# Expense Tracker

A simple Expense Tracker built with Node.js, Express, PostgreSQL, and EJS.

## Features

- Add expenses
- View expenses
- Edit expenses
- Delete expenses
- Automatic date and time tracking

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- PostgreSQL
- EJS

## Installation

1. Clone the repository

```bash
git clone <repo-url>
```

2. Install dependencies

```bash
npm install
```

3. Create PostgreSQL database

```sql
CREATE DATABASE expense_tracker;
```

4. Run the application

```bash
node index.js
```

5. Open:

```txt
http://localhost:3000
```
